# 未来のこと

妄想LPの、妄想のもとにする未来の技術とくらしのまとめです。https://mousou-lp.github.io/mirai/ に出ています。

妄想LPのモットーは、次のとおりです。

> 未来の技術と自分の偏愛から、架空のサービスを妄想する。その未来を考えることで、いまの自分の生き方に干渉して、ポジティブな変化を起こす。

ここはその「未来の技術」の側を集める場所です。読んだ人が、自分の偏愛とかけあわせて、LPを作ったり、LPのリクエストを書いたりできるようにします。

遊び場なので、だれが足しても直してもかまいません。mainに入ると、数分で自動で公開されます。

## 未来のことを足す

`futures/`に、1件につき1つのMarkdownのファイルを置きます。ファイル名は英小文字・数字・ハイフンで、そのままページのURLになります（`futures/moon.md`なら`/mirai/moon/`）。

```markdown
---
title: 月に、人が住みはじめる
when: 2040年代から
area: 宇宙
summary: 60字までの、どんな未来かの説明。
---

## いまどこまで来ているか

## 実現すると、くらしはどう変わるか

## 妄想のタネ

- 偏愛とかけあわせるための問いを、3つくらい
```

- `area`が同じものは、一覧で同じまとまりに入ります。いまは、くらし・からだ・食べもの・移動・宇宙があります。新しい分野を書けば、まとまりも増えます
- 3つの見出しは、どれも必ず入れてください。「妄想のタネ」は、読んだ人が自分の好きなものを当てはめられる問いにします
- どれも予想なので、言い切りすぎないようにします。確かめた話は「〜しています」、まだわからない話は「〜かもしれない」と書き分けます
- 実在する会社の名前や、出どころのわからない数字は書きません

## 手元で見る

```bash
node build.mjs && python3 -m http.server 5181 -d dist
```

`node build.mjs --check`で、書き方の誤り（足りない項目や見出し）だけを確かめられます。同じチェックがmainに入るときとプルリクエストでも動き、通らないと公開されません。

## しくみ

- `build.mjs`が`futures/*.md`を読み、一覧と1件ずつのページを`dist/`に書き出します。ほかに入れるものはなく、Node 20以上があれば動きます
- 同じ中身を`futures.json`としても出しています。[妄想のタネ](https://github.com/mousou-lp/tane)が、これを読んで未来の選択肢にしています。項目の名前を変えるときは、妄想のタネも合わせて直します
- 見た目は`src/style.css`です。色・余白・文字の大きさは、ポータルと同じ値を使っています
- 公開は`.github/workflows/pages.yml`が、GitHub Pagesに出します。お金はかかりません
- 検索エンジンには載りません。ポータルの`robots.txt`が、`/mirai/`もまとめて止めています
